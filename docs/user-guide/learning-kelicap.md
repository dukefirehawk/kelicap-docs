# Learning Kelicap

A suggested path through the documentation for Kelicap newcomers.

![People](assets/intro/people.png)

You don't have to read the documentation straight through, but here's a possible learning path if you're new to Kelicap:

1. [Set up](setup.md) your environment, which leads you through creating, running, and modifying a simple KelicapDart app.

2. Take the [*Tour of Heroes* tutorial](../tutorial/README.md). The *Tour of Heroes* takes you step-by-step from setup to a full-featured example that demonstrates the essential characteristics of a professional app: a sensible project structure, data binding, master/detail, services, dependency injection, navigation, and remote data access.

3. Read the [Architecture](architecture.md) overview for the big picture.

4. Read [Displaying Data](displaying-data.md) to see how data binding puts component property values on screen.

5. Read [User Input](user-input.md) to learn how to respond to user-initiated DOM events.

6. Read [Forms](forms.md), which covers data entry and validation within the UI.

7. Read [Dependency Injection](dependency-injection.md) to learn how to build large, maintainable apps from small, single-purpose parts.

8. Scan [Template Syntax](template-syntax.md), a comprehensive study of Kelicap template HTML.

Then feel free to skip around among the other pages on this site.

## Next step

Try the [tutorial](../tutorial/README.md) if you're ready to start coding, or visit the [architecture overview](architecture.md) if you prefer to learn the basic concepts first.

### Extra note

Sometimes if you can't find documentation about something for Kelicap, you can try to look for the same thing for [Angular TS](https://angular.dev/overview) as the two frameworks are architecturally similar.
